# 冷蔵庫販買マスター Risa Edition Ver.2.1

GitHub Pages でそのまま公開できる静的PWAです。

## 主な機能
- 6メーカー比較：Panasonic / 日立 / 三菱電機 / 東芝 / SHARP / AQUA
- 「なぜおすすめ？」まで表示するメーカー詳細
- 冷蔵庫の基礎
- 容量の選び方
- 設置・搬入チェック（端末保存）
- 販買モード（ニーズ診断）
- 今日のミニテスト10問
- お気に入り（端末保存）
- 名前・ミッション進捗（端末保存）
- iPhone / iPad ホーム画面追加対応

## GitHub Pages
Repository name: `reizo-master`
公開URLの例: `https://risaleo.github.io/reizo-master/`

機能・仕様はシリーズや型番で異なります。実際の販売時はメーカー公式の対象型番仕様を確認してください。
